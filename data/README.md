# Data provenance
events.csv contains synthetic retail sale events generated for this portfolio with random.Random(42).
5,000 original events, 100 exact duplicates, 30 invalid quantities, 20 newer corrections.
Identifiers are invented. No employer data or external tutorial dataset is used. Data license: CC0 1.0.
The original five-row sales.csv is retained for starter attribution, but is not pipeline input.
updated_at is a source version timestamp in naive UTC, not ingestion wall-clock time.
